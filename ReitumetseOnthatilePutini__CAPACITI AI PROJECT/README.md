# ProductivityAI Assistant | Reitumetse Onthatile Putini

**An AI-Powered Productivity Assistant for the modern workplace**

This project delivers a practical, ready-to-use AI solution that helps professionals automate repetitive tasks such as writing emails, summarizing meeting notes, and planning daily work.

> No coding required. Works with ChatGPT, Claude, Gemini or any similar large language model.

---

## Project Overview

Professionals spend a significant amount of time every day on repetitive tasks. This project solves that problem by providing a carefully engineered AI assistant that can:

1. **Generate professional emails** (with different tones and audiences)
2. **Summarize meeting notes** (key points, decisions, action items, owners & deadlines)
3. **Create prioritized task plans** (daily/weekly schedules with time-optimization suggestions)

The solution is delivered as a single, high-quality **System Prompt** that turns any modern AI chatbot into a specialized workplace productivity assistant.

---

## Features

| Feature | What it does |
| --- | --- |
| **Smart Email Generator** | Creates context-aware professional emails. Supports formal, friendly, and persuasive tones. Adapts to audience (client, manager, team). |
| **Meeting Notes Summarizer** | Converts long notes into structured summaries with Key Points, Decisions Made, and Action Items (including owner and deadline). |
| **AI Task Planner** | Builds prioritized daily or weekly plans based on urgency and importance. Suggests realistic time blocks. |
| **Chatbot Interface** | One conversational assistant that automatically handles all three features. |

## How to Use (3 Simple Steps)

### Step 1 – Copy the System Prompt

Open the file `SYSTEM_PROMPT.md` and copy the entire prompt.

### Step 2 – Open any AI chatbot

- [ChatGPT](https://chat.openai.com)
- [Claude](https://claude.ai)
- [Gemini](https://gemini.google.com)
-  any other large language model chat interface

### Step 3 – Paste and start working

Paste the System Prompt as your **first message**. After that, just talk normally.

**Example requests you can try immediately:**

```
Write a formal email to my manager asking for two days leave next week because of a family event. Keep it short and polite.
```

```
Please summarize the following meeting notes. Extract Key Points, Decisions Made, and Action Items (with owner and deadline):

[Paste your long notes here]
```

```
I have these tasks for tomorrow. Create a prioritized daily plan with rough time blocks:

1. Finish client proposal (due 3pm)
2. Reply to 8 emails
3. Team standup at 10am
4. Research new competitor pricing
5. Update project tracker
6. Call supplier about delayed delivery
```

## Responsible AI Practices

- Every response ends with a clear reminder to review and edit before sending or acting.
- The assistant is instructed **never** to invent facts, names, dates, or numbers.
- Users remain fully responsible for the final content.
- No sensitive data is stored beyond the current conversation.
